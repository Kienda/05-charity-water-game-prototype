# Asset credits

## Visuals

- `images/kumbala-savanna.png` — original AI-generated photorealistic environment created specifically for Thirst to Thrive with OpenAI's built-in image generation tool. Final prompt: “Create a realistic, documentary-style dry-season African savanna at golden hour, viewed from an elevated oblique game-map perspective, with dry grass, sandy paths, a dry riverbed, rocks, acacia trees, hazy mountains, a respectful earth-toned village on the right, and a natural spring in the lower-right; environment only, no people, text, logos, interface, cartoon style, fantasy, or exaggerated imagery.”
- `images/savanna-world.svg` — original code-authored SVG environment retained as a lightweight fallback and design source. It uses only vector shapes and gradients and has no third-party source material.
- Player, villagers, pump, spring, repair kit, water tank, signs, and wildlife markers — original HTML/CSS illustrations created for this project.

## Audio

No recorded or third-party audio files are used. Wind ambience, bird calls, footsteps, water, repair, and celebration feedback are synthesized at runtime with the browser's Web Audio API.

## Brand reference

The yellow, black, white, simple typography, and hopeful messaging are inspired by charity: water. This project is educational and is not an official charity: water product.
